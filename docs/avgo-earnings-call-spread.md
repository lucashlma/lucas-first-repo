# AVGO 期权 · 赌财报（370/420 debit call spread）

> 记录日：2026-08-31  
> 标的：Broadcom (`AVGO`)  
> 事件：[FY2026 Q3 财报](https://www.broadcom.com/company/news/financial-releases/64621) 于 **2026-09-02 盘后** 公布，电话会当天 14:00 PT。

**免责声明：** 这是个人交易日志，不是投资建议。期权可能在到期前归零；本结构的最大亏损等于已付净权利金。

---

## 一句话

跳空后高位震荡、空头一时接不回下跌趋势；现在靠近震荡下沿、小时 20EMA，方向上想做多，但马上财报，**不拿正股硬扛事件风险**，用有限亏损的看涨价差小赌怡情。

## 结构

| 项 | 内容 |
|----|------|
| 策略 | Debit call spread（买低卖高，净支出权利金） |
| 到期 | **2026-09-18** |
| 长腿 | **Buy call 370** |
| 短腿 | **Sell call 420** |
| 建仓 | **13.35** / 组（净借方） |
| 止损 | **仓位止损**（亏完权利金即止，不再加码、不加正股） |
| 止盈 | 最乐观：财报大涨、现货来到下跌段起点 **420** 附近 → 直接止盈；其他路径跟价格行为 |

## 到期结构（每组 ×100）

宽度 \(420 - 370 = 50\)。

| 指标 | 每组 | 美元 |
|------|------|------|
| 净借方 / 最大亏损 | 13.35 | **$1,335** |
| 最大盈利 | \(50 - 13.35 = 36.65\) | **$3,665** |
| 盈亏比 | 36.65 / 13.35 | **约 2.75 : 1** |
| 到期打平 | \(370 + 13.35\) | **383.35** |

现货到期在 370 以下：两腿都废，亏 13.35。  
现货到期在 420 及以上：价差走满宽度 50，赚 36.65。  
现货卡在 370–420：内在价值 = \(S - 370\)，盈亏 = \(S - 383.35\)。

短腿 420 同时是「下跌段起点」的乐观目标，也是价差封顶的位置：再往上多出来的涨幅归短腿买方，本策略不再加杠杆去追。

## 为什么用价差而不是买 370 单 call

- 财报前后隐含波动通常抬高；单买 call 容易「方向对了但 IV crush 吃掉溢价」。
- 卖出 420 call 对冲掉一部分时间价值和波动溢价，把最大亏损锁在已付的 13.35。
- 「仓位止损」= 接受定义为 13.35 的上限，不另设现货止损去提前斩结构（除非价格行为明确失效、决定主动平仓）。

## 出场

1. **乐观**：跳空/趋势把现货送到下跌段起点 **420** 附近 → 平掉整组，落袋接近最大利润的一段，不赌更高。
2. **一般**：未到 420，按价格行为（震荡上沿、假突破、财报后重新走弱）决定减仓或持有到期。
3. **失败**：方向错了就让仓位亏完或主动按不利价平掉，**不补仓、不转正股**。
