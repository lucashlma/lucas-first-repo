# 期权止盈下单方式

**结论：** 多头权利仓止盈优先用**限价平仓单**挂目标权利金；需要自动出场时，用券商**止盈条件单**（或 OCO：止盈 + 止损）。避免只靠市价追着平，也尽量不要把「赌到期行权」当成止盈手段。

本文按场内期权（ETF / 股指 / 商品等）持仓后主动止盈理解，不构成投资建议；具体委托名称以各券商客户端为准。

## 按场景推荐

| 场景 | 推荐下单方式 | 说明 |
|------|--------------|------|
| 已算好目标权利金 | **限价平仓**（卖平多头 / 买平空头） | 价格可控，最常用；流动性差时可能不成交 |
| 希望到价自动走 | **止盈条件单**（触发价 → 限价或市价平仓） | 盯盘成本低；注意触发后仍可能滑点 |
| 止盈与止损一起挂 | **OCO / 止盈止损组合条件单** | 一侧成交后自动撤另一侧，适合纪律化出场 |
| 利润分档锁定 | **分批限价平仓** | 例如先平 1/2，余仓上移止盈价 |
| 临近到期、只想尽快了结 | **对手方最优 / 市价剩余转限价** 等 | 求成交优先；权利金跳动大时滑点风险高 |
| 按标的涨跌止盈 | **标的价格触发的条件平仓** | 适合「标的到某点就走人」，与权利金目标止盈不同 |

## 多头 vs 空头

- **买入开仓（多头）止盈：** 对原合约做**卖出平仓**；止盈价一般高于开仓权利金（目标卖价）。
- **卖出开仓（空头）止盈：** 对原合约做**买入平仓**；止盈价一般低于开仓权利金（目标买回价更便宜）。
- 开平方向、备兑/保证金规则因交易所与账户权限而异，下单前核对持仓方向与可平数量。

## 常用参数怎么设

1. **目标价：** 按权利金报价（不是标的点数），结合买卖价差留一点余量。
2. **触发价（条件单）：** 可设在权利金，或设在标的价格；两者含义不同，勿混用。
3. **触发后委托：** 优先「触发后限价」控滑点；流动性极差或急平再用市价类。
4. **有效期：** 当日有效需每日重挂；支持「撤销前有效」的条件单适合中长线持仓。
5. **数量：** 可先部分平仓锁定利润，剩余仓位继续用条件单保护。

## 推荐工作流

1. 开仓后立刻写下：目标权利金、最大可接受亏损、是否分批。
2. 流动性正常时，主单用**限价平仓**挂止盈；同时挂**止损条件单**（或直接上 OCO）。
3. 权利金快速跳动、挂单不易成交时，改为更靠近盘口的限价，或缩小单笔数量分批出。
4. 临近到期、时间价值衰减加快时，优先主动平仓止盈，而不是默等到期。

## 注意

- 期权价格受标的、波动率、时间价值共同影响；标的到了目标，权利金未必到你的止盈价。
- 涨跌停、熔断、集合竞价、无对手盘时，条件单可能触发但平不掉或滑点很大。
- 组合策略（如垂直价差）止盈通常要按**组合或各腿分别**处理，不要只平一条腿除非有意改结构。
