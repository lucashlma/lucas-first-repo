## 「卖 Put 进、卖 Call 出」在干什么？

### 1. 卖 Put = 开保险公司 + 潜在接货

- 你收对方一笔保费，承诺：跌破行权价时，你必须按行权价买走股票。  
- 未跌破 → 白赚保费。  
- 跌破 → 按约定价接货，但成本已被保费摊薄。  
- **硬前提：** 账户里要有足够现金（他常把现金放在 T-Bill 上继续生息），能扛住被行权。

他自己的说法大意是：只是又开了间保险公司，赚点保费；这是「潜在接货」，不是赌短期涨跌。

### 2. 卖 Call（通常是 Covered Call）= 给持股找高价买家

- 手里已有正股作抵押，再卖 Call：涨过行权价时，你有义务按约定价卖出。  
- 未涨过 → 再收一笔保费。  
- 涨过 → 按约定高价出货（「卖 Call 出」）。

### 3. 完整循环（长线短做）

1. 先研究清楚公司，形成长期价值判断。  
2. 价格相对合理/偏低时 → **卖 Put**，收保费，现金继续吃利息。  
3. 未被行权 → 保费落袋，下一轮继续卖 Put。  
4. 被行权 → 低价（相对他的估值）拿到正股。  
5. 股价偏高时 → **卖 Covered Call**，再收保费。  
6. Call 被行权 → 高价卖出，回到现金，回到第 2 步。

标题里的「卖 call 出卖 put 进」指的就是这个进出闭环，而不是左右互搏的裸赌波动。

## 他反复强调的边界

- **不赚认知以外的钱**：不了解公司就不卖 Option；没有通用「期权模板」，只有「这家公司的策略」。  
- **几乎只卖不买**：买期权偏赌博；卖期权在他框架里是做生意（收时间与概率的钱）。  
- **过低不卖 Call、过高不卖 Put**：怕该拿的没拿到、该接的接贵了。  
- **目标克制**：跑赢标普 / 国债一类基准即可，不为超额利润硬上杠杆。  
- **现金与抵押**：卖 Put 要备足接货现金；卖 Call 通常要有对应持股（Covered）。

同逻辑也曾用在英伟达、苹果、腾讯、泡泡玛特等标的上（例如「英伟达保险公司」「泡泡玛特保险公司正式开张」一类表述）。
