Claude × TradingView：接进看盘台

项目：tradesdontlie/tradingview-mcp

工具只操作本机 TradingView Desktop，不自动实盘下单；需合法订阅。笔记供搭建学习，非投资建议。
一句话： 用 MCP 把 Claude Code 接到本机 TradingView（Chrome DevTools Protocol），实现看盘、写 Pine、出研报、Replay 复盘——把交易员流程固化成 AI 工作流。

视频能力对照

自己看盘chart-analysis：报价、指标、Pine 线/标签、截图
写策略pine-develop：写 → 注入 → 编译 → 修错
出研报strategy-report：回测指标 + 成交 + 权益曲线
远程复盘replay-practice：逐步走 K、模拟买卖
蒸馏交易员对齐其布局/指标，把分析步骤写成 skills/提示词

操作步骤

1. 安装

git clone https://github.com/tradesdontlie/tradingview-mcp.git ~/tradingview-mcp
cd ~/tradingview-mcp
npm install

2. MCP 配置

写入 ~/.claude/.mcp.json（或项目 .mcp.json）：

{
  "mcpServers": {
    "tradingview": {
      "command": "node",
      "args": ["/绝对路径/tradingview-mcp/src/server.js"]
    }
  }
}

3. 调试口启动 TradingView

  • 推荐：Claude 调用 tv_launch
  • 或脚本：launch_tv_debug_mac.sh / .bat / _linux.sh
  • 手动：TradingView --remote-debugging-port=9222

4. 验活

重启 Claude Code，说：Use tv_health_check to verify TradingView is connected

可直接贴给 Claude 的安装句

Install the TradingView MCP server. Clone https://github.com/tradesdontlie/tradingview-mcp.git, run npm install, add it to my MCP config at ~/.claude/.mcp.json, and launch TradingView with the debug port. Then verify with tv_health_check.

前置条件

  • TradingView Desktop + 付费订阅
  • Node.js 18+
  • Claude Code（MCP）
  • 本机打开端口 9222

不连 TV 服务器、不绕付费墙、不替你实盘下单。
