段永平「保险公司式」期权策略

主题：卖 Put 进、卖 Call 出，以及 SpaceX 一笔约 232 万美元权利金的实盘

免责声明：公开信息整理与学习笔记，不构成投资建议。期权有杠杆与强制接货/交割风险，勿盲目模仿。
一句话结论： 段永平几乎只卖期权、不买期权——在看好的好公司上，用卖 Put（潜在接货）和卖 Call（潜在出货）收「保费」，把长线价值判断做成可循环的现金流生意（「开保险公司」「长线短做」）。

SpaceX 这笔单

雪球「大道无形我有型」晒出 SpaceX（SPCX）期权成交，并称「支持一下马斯克的梦想」：

方向Sell to Open Put（卖出看跌）
数量1000 张（约 10 万股）
行权价$115
到期2026-12-18
成交权利金约 $23.26 / 股
合计保费约 232 万美元
名义接货规模约 1150 万美元（标题中的「1150 万交易」）
若被行权有效成本约 $91.74（115 − 23.26）
期限粗算约 5 个月，相对行权价约 25%，年化约 60%（示意）
  1. 到期价 ≥ 115： Put 作废，232 万保费落袋。
  2. 到期价 < 115： 按 115 接货；成本被保费摊薄。前提是本来就愿意持有。

卖 Put 进、卖 Call 出

1. 卖 Put = 保险公司 + 潜在接货

  • 收保费，承诺跌破行权价时按约定价买走股票。
  • 未跌破 → 白赚保费；跌破 → 接货但成本已被摊薄。
  • 硬前提： 备足现金（常放 T-Bill 生息），能扛被行权。

2. 卖 Call（多为 Covered Call）= 高价出货通道

  • 有正股抵押再卖 Call：涨过行权价则有义务按约定价卖出。
  • 未涨过再收保费；涨过则「卖 Call 出」。

3. 长线短做循环

  1. 研究公司，形成长期价值判断
  2. 价格合理/偏低 → 卖 Put，现金继续吃利息
  3. 未被行权 → 保费落袋，继续卖 Put
  4. 被行权 → 拿到正股
  5. 股价偏高 → 卖 Covered Call
  6. Call 被行权 → 高价卖出，回到现金，循环

他强调的边界

  • 不赚认知以外的钱；不了解公司就不卖 Option
  • 几乎只卖不买期权
  • 过低不卖 Call、过高不卖 Put
  • 目标克制：跑赢标普 / 国债一类基准即可
  • 卖 Put 备现金，卖 Call 通常要有持股

同逻辑也曾用于英伟达、苹果、腾讯、泡泡玛特等（「××保险公司」）。
