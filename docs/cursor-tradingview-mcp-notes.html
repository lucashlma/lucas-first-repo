Cursor × TradingView MCP

灵感来自 BV16Dgr61EFU，本仓库接到 Cursor
上游：tradesdontlie/tradingview-mcp

只操作本机 TradingView Desktop，不自动实盘下单；需合法订阅。非投资建议。
直接跑： 
bash scripts/setup-cursor-tradingview.sh
bash scripts/install-and-launch-tradingview.sh
node tools/tradingview-mcp/src/cli/index.js status
Cursor → Settings → MCP 启用 tradingview。云环境已实测 CDP 连通并可读写图表。
架构： Cursor Agent ↔ MCP (stdio) ↔ CDP :9222 ↔ TradingView Desktop
