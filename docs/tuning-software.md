# 调音软件选型建议

**结论：** 日常人声后期以 **Celemony Melodyne** 做音准与乐句编辑；需要明显电子感时用 **Antares Auto-Tune Pro**。

本文按录音棚 / 后期人声修音场景选型（非吉他调音器、非直播实时变声）。

## 按场景推荐

| 场景 | 推荐 | 理由 |
|------|------|------|
| 精细修音、自然校正 | **Celemony Melodyne** | 音符级编辑最强，适合流行 / R&B 等人声后期 |
| 风格化 Auto-Tune 效果 | **Antares Auto-Tune Pro** | 经典 T-Pain / 流行效果，实时与图形模式都成熟 |
| 预算有限、够用 | **Waves Tune Real-Time** 或 DAW 自带（Logic Flex Pitch / Cubase VariAudio） | 成本低，精细度不如 Melodyne |
| 免费 / 开源入门 | **GSnap** / **MAutoPitch** 等 | 仅适合试水，不作为正式制作主推 |

## 选型理由

- **Melodyne**：把人声拆成可编辑的音符，音高、时值、音质可单独调整，适合「听不出修过」的自然校正。
- **Auto-Tune Pro**：实时跟踪与图形模式成熟，适合故意做出机械感、流行电子人声效果。
- **预算方案**：Waves 或 DAW 内置工具能覆盖基础音准问题；复杂乐句、多音、精细气口处理仍建议上 Melodyne。
- **免费工具**：可验证工作流与听感，正式发行级制作不建议依赖。

## 推荐工作流

1. 录完干声后，先用 **Melodyne** 修正音准与个别乐句。
2. 若曲风需要明显 Auto-Tune 音色，再挂 **Auto-Tune Pro**（或同类）做风格化处理。
3. 预算紧张时，先用 DAW 自带或 Waves，确认瓶颈后再升级 Melodyne。
