# 深圳购房观察策略（个人）

更新日期：2026-08-08

## 买家画像

- 深户，社保约10年，首套
- 离异带娃
- 工作：前海
- 流动性资产：现金100万 + 股票350万
- 父母小户型可变现：160–180万（须确认仍为父母名下）
- 税后月薪：4万；年底奖金约50万；四年期权约40–50万（不计入月供）

## 硬约束

| 项目 | 标准 |
|---|---|
| 总价 | 主攻 650–700万；父母房未变现时先看 620–650万 |
| 首付 | 约 280–320万（约40%–45%） |
| 贷款 | ≤410万 |
| 月供 | ≤1.7万（占月薪约40%–43%） |
| 现金留存 | ≥50万 |
| 股票保留 | 尽量 ≥250万 |
| 产品 | 三房可分间，有电梯，近地铁 |
| 产权 | 红本商品房优先；满二/满五优先 |
| 通勤 | 门到门前海尽量 30–40 分钟内 |

## 板块优先级

1. 南山前海 / 大新 / 南头
2. 宝安中心 / 新安（同价位显著更新更好时）
3. 福田（仅备选）

## 一票否决

- 无电梯且楼层高
- 无法分间或户型严重浪费
- 主干道噪音大
- 近半年几乎无成交
- 产权复杂 / 非商品房住宅

## 谈判规则

- 核心区优质三房议价常见 5%–8%
- 必须比对同小区近 3–6 个月同户型成交
- 高于成交中枢且零议价：放弃
